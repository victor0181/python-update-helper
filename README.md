**一键把本机的 Python 环境收拾干净。**

自动发现本机所有解释器 → 测速挑出最快的国内 pip 镜像 → 写入 `pip.ini` → 升级 pip → 导出已装库清单。

纯标准库实现，**零第三方依赖**，Python 3.7 及以上均可运行。双击一次就完事。

## 它解决什么问题

国内直连 `pypi.org` 往往慢到让人放弃安装。手动换源又要逐个解释器改配置文件——virtualenv、conda 环境、多个 Python 大版本共存时，很容易漏掉某一个。

更糟的是「改错一处，全盘变慢」，而你未必知道是哪一处。

这个工具把这件事做成**幂等**的：跑一次，本机每个 Python 都被配好镜像源；再跑一次，结果完全一致，不叠加、不污染配置。

## 快速开始

### 方式一：双击

双击 **`一键配置.bat`**。它会自动挑一个可用的解释器，并优先以**无控制台窗口**的方式打开图形界面。

> `一键配置.bat` 被**刻意**写成纯 ASCII + CRLF，这不是疏忽：`cmd.exe` 按当前代码页逐字节读取批处理文件，一旦混入非 ASCII 字符，行边界会整体错位并报「不是内部或外部命令」。所以所有中文文案都写在 `.py` 里，由 Python 负责输出。
>
> 仓库里的 `.gitattributes` 已把这条约束固化（`*.bat text eol=crlf`），否则换到别的平台克隆时换行符会漂移，直接踩坏它。

### 方式二：命令行

```bash
python pip_helper.py                 # 全自动：配镜像源 + 升级 pip + 列出已装库
python pip_helper.py --list-only     # 只看清单，绝不改动任何配置
python pip_helper.py --dry-run       # 预览将要做什么，零写入
python pip_helper.py --restore       # 把 pip 源改回官方 PyPI
python pip_helper.py --help          # 查看全部参数
```

命令行版是能力的**唯一真源**，图形界面只是它的前端——不存在「只有图形界面才能做到」的操作。

## 命令行参数

### 日常用

| 参数 | 作用 |
| --- | --- |
| *（不加参数）* | 全自动：发现 → 测速 → 配源 → 升级 pip → 列库并导出 |
| `--list-only` | 只列出已装库，不改配置、不升级 pip |
| `--dry-run` | 预览将要做什么，不写任何文件、不执行安装 |
| `--restore` | 把 pip 源改回官方 PyPI（**只改源**，不升级 pip、不列库） |
| `-h, --help` | 查看全部参数 |

### 挑选要处理哪些解释器

| 参数 | 作用 |
| --- | --- |
| `-p, --python 路径` | 手动指定解释器，可重复；给了这个就**跳过自动发现** |
| `--exclude 关键词` | 跳过路径中含该关键词的解释器，可重复。例如 `--exclude WorkBuddy` 不碰工具自带的 Python |
| `--config-file 路径` | 指定要写入的 `pip.ini`（默认自动定位到 pip 真正读取的那份） |

### 挑选镜像

| 参数 | 作用 |
| --- | --- |
| `--mirror 名称` | 指定主镜像，跳过测速。可选：清华 TUNA / 阿里云 / 腾讯云 / 中科大 |
| `--no-probe` | 不测速，直接用预设顺序里的第一个 |
| `--trusted` | 同时写入 `trusted-host`（网络存在 SSL 拦截时使用） |

### 只做某一步（四者互斥）

| 参数 | 作用 |
| --- | --- |
| `--configure-only` | 只配置 pip 源，不升级 pip、不列出库 |
| `--upgrade-only` | 只升级 pip，不动源、不列出库 |
| `--probe-only` | 只测速镜像，不修改配置（此时不需要指定解释器） |

### 跳过某一步

| 参数 | 作用 |
| --- | --- |
| `--no-config` | 不动 pip 源配置 |
| `--no-upgrade` | 只配源和列库，不升级 pip |
| `--no-export` | 不导出清单文件 |

> 互相矛盾的组合会被**直接拒绝并说明原因**，而不是默默忽略。例如 `--configure-only --no-config` 会报「互相矛盾，那样一步都不会执行」，`--restore --mirror` 会提示 `--restore` 不需要指定镜像。
>
> 另有 `--discover-json` / `--probe-json` 两个隐藏参数，供图形界面取结构化结果，日常用不到。

## 工作原理

```text
① 发现解释器   →   ② 镜像测速   →   ③ 改写 pip.ini   →   ④ 升级 pip   →   ⑤ 导出清单
   py 启动器        清华 / 阿里        备份             逐解释器         清单/*.txt
   PATH / 注册表    腾讯 / 中科大      按行改写          pip install      带时间戳
   安装目录         取延迟最低         原子替换
   虚拟环境/conda   （并发探测）       只写一个主源
```

每一步都**独立 `try/except`**：某台解释器出问题只会让那一步失败，其余解释器继续处理。

`pip.ini` 的位置取自各解释器自己的 `pip config debug`，因此 virtualenv 内部的独立配置也能被正确定位——不会出现「改了全局源，虚拟环境却仍走官方源」的情况。

## 安全保证

改配置这件事最容易出岔子，所以这里的规矩是硬的：

- **只写一个主源**，不写 `extra-index-url`。多索引择优存在依赖混淆风险，这个取舍是刻意的。
- **用户自己的私有源会被保留**，只清理本工具以前写进去的镜像值。
- **按行改写**，保留注释、键名大小写、键顺序、空行，以及 CRLF / BOM / GBK 编码与文件里的其它段落。
- **先备份**成 `pip.ini.bak-时间戳`，再以「临时文件 + 原子替换」落盘——中途断电也不会留下半截文件。
- `--dry-run` 与 `--list-only` 保证**零写入**，可以先看清楚将要发生什么再动手。

## 图形界面

`pip_helper_gui.py` 是一个 tkinter 前端，适合不想看命令行输出的人：

- 先「扫描」列出所有解释器，再**勾选**要处理的；
- 一次只执行一个明确的操作，不搞「一键全干」；
- 扫描后**默认不勾选**标记为「当前助手」的那个解释器——也就是工具自身正在使用的 Python，避免顺手把自己依赖的环境改掉（对应命令行版的 `--exclude WorkBuddy`）。

## 系统要求

- **Windows**。核心逻辑本身跨平台，但注册表探测与「无窗口启动」是针对 Windows 实现的，macOS / Linux 未做实测。
- **Python 3.7+**，仅需标准库，不装任何第三方包。
- 图形界面需要 `tkinter`（官方安装包自带；部分精简发行版可能缺少）。

配置镜像源**不需要管理员权限**（写的是用户级 `pip.ini`）。但若要升级安装在 `Program Files` 下的系统级 Python 的 pip，可能需要以管理员身份运行。

## 常见问题

**会把我自己的私有源冲掉吗？**

不会。工具只认自己写过的镜像值，你的私有源（例如公司内网 index）会被保留。

**会不会误改我不想动的 Python？**

用 `-p` 只处理指定解释器，或用 `--exclude 关键词` 排除，也可以在图形界面里逐个勾选。工具自带的运行时建议加 `--exclude WorkBuddy`。

**跑完发现不对，怎么退回？**

两种方式：同目录会自动留下 `pip.ini.bak-时间戳`，直接覆盖回去；或执行 `python pip_helper.py --restore` 改回官方源。

**为什么清华 TUNA 偶尔报 403？**

见下方「已知情况」，是网络侧问题，与本工具无关，也不影响其它镜像。

**支持 macOS / Linux 吗？**

核心逻辑跨平台，但发现解释器的注册表探测、以及 `.bat` 启动入口是 Windows 专属。macOS / Linux 未经实测，需要自行调整。

**为什么所有中文都不在 `.bat` 里？**

因为 `cmd.exe` 按当前代码页逐字节读取批处理文件，非 ASCII 字符会让行边界错位。详见「快速开始」里的说明。

## 已知情况

- 清华 TUNA 在部分网络环境下测速可能返回 `403`（阿里云、腾讯云、中科大正常），疑似网络侧 WAF。若**全部**镜像都测不通，会退回预设顺序（清华优先），不会中断执行。
- 发现阶段的耗时主要花在**逐个启动 Python 进程**（每次约 0.5~1.6 秒），已改为并发探测以缩短等待。
- 若把工具放在盘符下一级目录（例如 `D:\pip助手`），向上遍历时会碰到盘符根目录，已跳过不遍历。
